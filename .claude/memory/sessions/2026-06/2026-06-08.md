## G. 시각 / Timezone 컨벤션

- **사람 / log / KST**: 모든 시각 표시는 KST (`Asia/Seoul`, `+09:00`)
- **DB / TIMESTAMPTZ**: UTC 저장. SQL 비교 시 `TIMESTAMPTZ 'YYYY-MM-DD HH:MM:SS+09'` 명시 (KST 기준 보고)
- **`now_kst()`**: `src.utils.time.now_kst()` 사용. Python datetime 직접 비교 시 항상 timezone-aware
- **변환**: `KST = UTC + 9`. 6/5 14:30 KST = 6/5 05:30 UTC

본 reconcile 스크립트 `TARGET_START_UTC = datetime(2026, 6, 5, 5, 30, 0, tzinfo=UTC)` 가 정확히 KST 14:30.
